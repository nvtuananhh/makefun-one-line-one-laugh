## What it does

`main.py` (Python 3, standard library only, no network) writes
one line to `/output/entry.txt` — a single funny line:

> The Wi-Fi went down for 12 minutes and my family discovered we live with strangers.

The line is 83 characters long. One twist, packed into the final
words: the outage lasts only 12 minutes, and the punchline is that
the family are strangers to each other. No setup longer than the
punchline needs, no second beat to dilute it. Every word earns
its place, and the turn is the joke.

## How to run

```sh
python3 main.py
```

## Output

Writes one line (83 characters) to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
